## 🌟 最新專案：透明肥皂除泡與防霧全工藝指南 (`crystal_soap_guide.html`)

針對**透明皂基 MP**、**氨基酸水晶皂**、**自製熱製透明皂 HP** 的除泡、防白霧、追求 95%+ 光學穿透率的極致手工皂工藝指南：
- **光學物理原理分析**：微米級氣泡的界面全反射（銀色亮點）與未溶膠束米氏散射（白霧感）。
- **材料與配方源頭控制**：
  - 氨基酸水晶皂基（谷氨酸表面活性劑，95%+ 透光率）vs 特級高透皂基 vs 傳統 MP 皂基比對。
  - 自製熱製 HP 油脂關鍵：30%~40% 蓖麻油增溶提透、精煉椰子油與硬脂酸；嚴格禁止未精煉植物油。
  - 100% 蒸餾水純度（杜絕金屬皂鈣沉澱）與液態山梨糖醇代糖促透。
  - 添加物防乳化：避免柑橘精油與乳化型香精，杜絕雲母粉礦物粉吸附微泡。
- **7 大物理排氣消泡絕技**：
  1. 密閉覆膜融化（防表面結皮與水分揮發）
  2. 單向「貼底慢劃」（嚴禁打蛋式攪打）
  3. 保溫靜置沉降法（60°C~65°C 水浴靜置 10~15 分鐘讓氣泡浮頂）
  4. 廚房紙巾平貼吸除表層浮沫
  5. 模具吹風機預熱 (~40°C) 與玻璃棒貼壁引流
  6. 95% 酒精雙重噴灑（入模前降張力 + 入模後瞬間破泡）
  7. 手持熱縮熱風槍 150°C~200°C 快速掃過 1 秒鏡面重融
- **互動式工具**：
  - 光學透光度與氣泡模擬器
  - 互動式標準 SOP 檢查清單（實時完成度進度條）
  - 一鍵複製文字版 SOP / 列印存檔模式
  - 繁簡中文（繁體中文 / 简体中文）即時無縫切換
