## 🌟 最新项目：透明肥皂除泡与防雾全工艺指南 (`crystal_soap_guide.html`)

针对**透明皂基 MP**、**氨基酸水晶皂**、**自制热制透明皂 HP** 的除泡、防白雾、追求 95%+ 光学穿透率的极致手工皂工艺指南：
- **光学物理原理分析**：微米级气泡的界面全反射（银色亮点）与未溶胶束米氏散射（白雾感）。
- **材料与配方源头控制**：
  - 氨基酸水晶皂基（谷氨酸表面活性剂，95%+ 透光率）vs 特级高透皂基 vs 传统 MP 皂基比对。
  - 自制热制 HP 油脂关键：30%~40% 蓖麻油增溶提透、精炼椰子油与硬脂酸；严禁未精炼植物油。
  - 100% 蒸馏水纯度（杜绝金属皂钙沉淀）与液态山梨糖醇代糖促透。
  - 添加物防乳化：避免柑橘精油与乳化型香精，杜绝云母粉矿物粉吸附微气泡。
- **7 大物理排气消泡绝技**：
  1. 密闭覆膜融化（防表面结皮与水分挥发）
  2. 单向“贴底慢划”（严禁打蛋式搅打）
  3. 保温静置沉降法（60°C~65°C 水浴静置 10~15 分钟让气泡浮顶）
  4. 厨房纸巾平贴吸除表层浮沫
  5. 模具吹风机预热 (~40°C) 与玻璃棒贴壁引流
  6. 95% 医用酒精双重喷洒（入模前降张力 + 入模后瞬间破泡）
  7. 手持热缩热风枪 150°C~200°C 快速扫过 1 秒镜面重融
- **交互式工具**：
  - 光学透光度与气泡模拟器
  - 交互式标准 SOP 检查清单（实时完成度进度条）
  - 一键复制文字版 SOP / 打印存盘模式
  - 导航栏自适应防折行设计，纯简体中文呈现
